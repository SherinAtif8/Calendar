# دليل الاستخدام اليومي - Daily User Manual

## 🔄 سير العمل اليومي (Daily Workflow)

### 1️⃣ إضافة اجتماع جديد

```
قاعدة البيانات → آخر صف جديد → املئي البيانات
```

| الخطوة | العمل | التفاصيل |
|--------|-------|----------|
| 1 | التاريخ | اختاري من التقويم |
| 2 | اليوم | يتولد تلقائياً |
| 3 | الوقت | من الساعة → للساعة |
| 4 | النوع | اختاري من القائمة المنسدلة |
| 5 | الاسم | اكتبي اسم الاجتماع |
| 6 | الحضور | اكتبي اسماء الحضور |
| 7 | الحالة | Scheduled (افتراضي) |

> 💡 **Tip**: الـ ID يتولد تلقائياً لما تدخلي التاريخ!

---

### 2️⃣ إلغاء اجتماع

```
1. اذهبي لـ Sheet "قاعدة البيانات"
2. لاقي الاجتماع اللي عايزة تلغيه
3. غيّري الحالة من "Scheduled" إلى "Cancelled"
4. املئي:
   • تاريخ الإلغاء (M): تاريخ اليوم
   • سبب الإلغاء (N): سبب الإلغاء
   • تم بواسطة (O): اسم الشخص اللي ألغى
5. ✅ الـ Script ينقله تلقائياً لـ "محفظة الإلغاء"
```

> ⚠️ **Warning**: لما تغيّري الحالة لـ Cancelled، الاجتماع هيتنقل فوراً للمحفظة ويتمسح من قاعدة البيانات!

---

### 3️⃣ تغيير موعد اجتماع (Move)

```
1. غيّري الحالة القديمة إلى "Moved"
2. أضيفي اجتماع جديد بالموعد الجديد
3. في الملاحظات، اكتبي "Moved from [التاريخ القديم]"
```

---

### 4️⃣ تحديد اجتماع كمكتمل (Completed)

```
بعد ما الاجتماع يخلص:
غيّري الحالة من "Scheduled" إلى "Completed"
```

> ✅ الخلفية هتبقى خضراء تلقائياً!

---

### 5️⃣ عرض الاجتماعات

#### 📅 العرض اليومي
```
Sheet: "عرض يومي"
Cell B1: ادخلي التاريخ (مثلاً: 01/06/2026)
→ هيظهر كل اجتماعات اليوم مرتبة بالوقت
```

#### 📆 العرض الأسبوعي
```
Sheet: "عرض أسبوعي"
Cell B1: ادخلي تاريخ الأحد (مثلاً: 07/06/2026)
→ هيظهر كل اجتماعات الأسبوع
```

#### 🗓️ العرض الشهري
```
Sheet: "عرض شهري"
Cell B1: السنة (2026)
Cell C1: الشهر (6)
→ هيظهر كل اجتماعات الشهر
```

---

### 6️⃣ مراجعة الإحصائيات

```
Sheet: "لوحة التحكم"
```

| الإحصائية | المعنى |
|-----------|--------|
| إجمالي الاجتماعات | كل الاجتماعات (المجدولة + المحفظة) |
| مجدولة | Meetings not yet held |
| مكتملة | Meetings already completed |
| ملغاة | Meetings in archive |
| مؤجلة | Meetings moved to new date |
| اجتماعات اليوم | Today's count |
| اجتماعات الأسبوع | This week's count |

## ❓ الأسئلة الشائعة (FAQ)

### Q: لغيت اجتماع بالغلط، إزاي أرجعه؟
**A**: اذهبي لـ Sheet `محفظة الإلغاء`، انسخي الصف، واعملي Paste في `قاعدة البيانات`، وغيّري الحالة لـ `Scheduled`.

### Q: إزاي أضيف اجتماع خارج القالب؟
**A**: أضيفي صف جديد في `قاعدة البيانات` وأملئي كل البيانات يدوياً.

### Q: إزاي أغيّر وقت EHA Pulse؟
**A**: غيّري في `قاعدة البيانات` الصفوف اللي فيها `EHA Pulse`.

### Q: إزاي أضيف شهر جديد؟
**A**: في Apps Script، شغلي `createNewMonthTemplate(month, year)`.

### Q: الـ Script مش شغال!
**A**: تأكدي إن:
1. الـ Trigger مضاف صح
2. أعمدة قاعدة البيانات مظبوطة
3. الحالة مكتوبة بالإنجليزي (Cancelled مش إلغاء)
